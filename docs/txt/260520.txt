1. 데이터베이스 & 테이블 제어 (DDL)
SHOW DATABASES;

의미: 데이터베이스 목록 확인

예시: show databases;

USE

의미: 사용할 데이터베이스 선택

예시: use mbasic;

SHOW TABLES;

의미: 테이블 목록 확인

예시: show tables;

DESC

의미: 테이블 구조(필드 속성) 확인

예시: desc userinfo;

DROP TABLE

의미: 테이블 삭제

예시: drop table userinfo;

CREATE TABLE ... LIKE

의미: 원본의 구조와 제약조건만 똑같이 복사

예시: create table userinfo_ex like userinfo;

CREATE TABLE ... AS SELECT

의미: 원본의 구조와 데이터를 복사 (기본키 제약조건은 미복사)

예시: create table userinfo_ex as select * from userinfo;

ALTER TABLE ... RENAME

의미: 테이블 이름 변경

예시: alter table users rename userinfo;

ALTER TABLE ... ADD

의미: 새로운 필드 추가

예시: alter table userinfo add email varchar(100);

ALTER TABLE ... CHANGE

의미: 필드명과 자료형을 동시에 수정

예시: alter table userinfo change email email2 varchar(50);

ALTER TABLE ... MODIFY

의미: 필드의 자료형(타입)만 수정

예시: alter table userinfo modify email2 varchar(100);

ALTER TABLE ... DROP

의미: 특정 필드 삭제

예시: alter table userinfo drop email2;

2. 데이터 조작 (DML)
INSERT INTO ... VALUES

의미: 테이블에 전체 필드 데이터 입력

예시: insert into userinfo values (1, 'aaa', 11);

INSERT INTO ... (...) VALUES

의미: 원하는 필드만 지정하여 데이터 입력 (순서 변경 가능)

예시: insert into userinfo (name, age) values ('bbb', 22);

INSERT INTO ... SELECT

의미: 다른 테이블의 데이터를 조회해서 한 번에 삽입

예시: insert into userinfo_re1 select * from userinfo_ex;

UPDATE ... SET ... WHERE

의미: 조건에 맞는 데이터 수정

예시: update userinfo set age=55 where no=5;

DELETE FROM ... WHERE

의미: 조건에 맞는 데이터 삭제

예시: delete from userinfo where no=5;

DELETE FROM

의미: 테이블의 전체 데이터 삭제

예시: delete from userinfo;

SET SQL_SAFE_UPDATES

의미: 세이프 업데이트 모드 설정/해제 (키값 없이 수정/삭제 시 에러 방지)

예시: SET SQL_SAFE_UPDATES = 0; -- 해제 (1은 다시 설정)

3. 데이터 검색 및 필터링 (SELECT 조건절)
SELECT * FROM

의미: 테이블의 전체 데이터 검색

예시: select * from emp;

SELECT ..., ... FROM

의미: 특정 필드만 선택해서 검색

예시: select no, name from userinfo;

DISTINCT

의미: 중복된 행을 제거하고 종류별로 한 번만 출력

예시: select distinct job from emp;

AS

의미: 필드명에 별칭(이름 바꾸기) 부여

예시: select sal * 12 as 'annsal' from emp;

= / <> (또는 !=)

의미: 같다 / 다르다 (등가 비교 연산자)

예시: select * from emp where job <> 'CLERK';

<, <=, >, >=

의미: 크기 비교 (대소 비교 연산자)

예시: select * from emp where sal >= 3000;

AND / OR

의미: 그리고 (모두 만족) / 또는 (하나라도 만족)

예시: select * from emp where deptno = 30 and job = 'salesman';

BETWEEN ... AND

의미: 특정 범위 내의 값 추출 (시작값과 끝값 포함)

예시: select * from emp where sal between 2000 and 3000;

IN (...)

의미: 괄호 안에 적힌 값 중 하나라도 일치하는지 비교

예시: select * from emp where job in ('MANAGER', 'CLERK');

IS NULL

의미: 데이터가 비어 있는(NULL) 상태인지 비교 (=연산자 사용 불가)

예시: select * from emp where comm is null;

IS NOT NULL

의미: 데이터가 채워져 있는(NULL이 아닌) 상태인지 비교

예시: select * from emp where mgr is not null;

LIKE

의미: 와일드카드(%, _)를 사용한 문자열 매칭 패턴 필터링

예시:
select * from emp where ename like 'S%'; -- S로 시작하는 이름
select * from emp where ename like '_L%'; -- 두 번째 글자가 L인 이름

NOT

의미: 뒤에 오는 조건을 반대로 뒤집음

예시:
select * from emp where sal not between 2000 and 3000;
select * from emp where job not in ('CLERK');

ORDER BY ... [ASC|DESC]

의미: 특정 필드 기준으로 데이터 정렬 (ASC 오름차순 생략가능 / DESC 내림차순)

예시: select * from emp order by deptno asc, sal desc;

LIMIT

의미: 출력할 행의 개수 제한 (시작위치, 개수)

예시: select * from userinfo order by age desc limit 0, 2;
